## **Production Notes:**

**Recording Setup:**
- Use Chrome full-screen, disable browser extensions
- Record at 1440p, 60fps
- Use mouse movement animation tool for smooth cursor
- Enable dark mode recording only

**Transitions:**
- Page navigation: simulate thread-stitch transition (quick dark overlay + golden line across)
- Section reveals: use the natural fade-up animations already built in
- Highlight key interactions with subtle screen glow

**Voiceover Tone:**
- Confident, futuristic, slightly cinematic
- Emphasize "intelligent," "verified," "real-time," "secure"
- Pause briefly after feature names for visual impact

**Music:**
- Ambient electronic, building intensity
- Subdued during demos, slightly prominent during transitions
- Gold/tan frequency emphasis to match brand

**Duration:** 2:20 ± 5 seconds

**Post-Production:**
- Add golden thread overlay animation on major section cuts
- Subtle particle effects matching ParticleBackground
- Lower-third text for feature names (serif, gold) when mentioned
- End with: "astrathreads.com" URL + GitHub repository link
